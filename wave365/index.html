Reliable reminders — Calendar

The right way to get every reminder, on time, even when the app is closed. Download the calendar file below and open it on your phone — Apple Calendar (or Google Calendar) imports all 365 days as real events with built-in 10-minute alerts. After importing once, your phone handles every notification natively.

Download all 365 days as a calendar
On iPhone: tap the downloaded file → it opens in Calendar → "Add All" → choose your calendar.
On Mac: double-click the file → Calendar opens → confirm import.
On Android: open the file in Google Calendar app → import to your account.

In-app notifications (foreground only)

These fire only while the app is actually open. iOS suspends backgrounded PWAs, which kills any scheduled in-app reminders — that's why the calendar import above is the reliable option. Use these for live coaching while you're working, not as a primary alarm.
